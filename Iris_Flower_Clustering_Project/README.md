# Iris Flower Clustering Project

## Project Overview
The Iris Flower Clustering Project uses Unsupervised Machine Learning to group similar Iris flowers using the K-Means clustering algorithm.

Principal Component Analysis (PCA) is used to reduce the dimensions of the dataset and visualize the clusters.

## Dataset
The project uses the built-in Iris dataset from Scikit-learn.

Dataset contains:
- 150 flower records
- 4 numerical features
- 3 actual flower species

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## Algorithms Used
1. K-Means Clustering
2. Principal Component Analysis (PCA)
3. Elbow Method

## Project Steps
1. Load the Iris dataset.
2. Explore and preprocess the data.
3. Apply feature scaling.
4. Perform K-Means clustering.
5. Visualize the clusters.
6. Apply the Elbow Method.
7. Apply PCA to reduce dimensions.
8. Visualize PCA results.
9. Save the final clustering results.

## How to Run
1. Install the required libraries using:

   `pip install -r requirements.txt`

2. Run the Python program:

   `python iris_clustering.py`

## Conclusion
The project successfully applies K-Means clustering to group similar Iris flowers. PCA reduces the dataset from four dimensions to two dimensions, making visualization easier. The project demonstrates the practical use of unsupervised machine learning.
